Put your project videos in this folder.

1. Save the video here as an MP4, e.g. washbook.mp4 (ideally under 50MB, 1080p or smaller).
2. Open src/data/projects.js and set that project's  video: "washbook.mp4"
3. Run  npm start  to check it, then  npm run deploy  to publish.

GitHub won't accept a single file over 100MB, so compress anything bigger first
(HandBrake's "Fast 1080p30" preset works well).
